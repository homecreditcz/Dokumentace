Tento resource slouží ke změně stavu žádosti (`stateReason`) na požadovaný. Následující tabulka obsahuje povolené přechody pro tento resource.

| Aktuální stateReason žádosti (z) | Dostupné přechody (na) |
| --- | --- |
| `PROCESSING_REDIRECT_NEEDED` | `PROCESSING_APPROVED`, `PROCESSING_SIGNED`, `READY_TO_SHIP`, `REJECTED`, `CANCELLED_NOT_PAID` |
| `PROCESSING_APPROVED` | `PROCESSING_SIGNED`, `READY_TO_SHIP`, `CANCELLED_NOT_PAID` |
| `PROCESSING_SIGNED` | `READY_TO_SHIP`, `CANCELLED_NOT_PAID` |
| `READY_SHIPPED` | `CANCELLED_NOT_PAID` |
| `READY_DELIVERED` | `CANCELLED_RETURNED` |

> **POZN:** Tato akce simuluje reálný proces žádosti, což znamená, že žádost může projít jedním nebo více kroky (`stateReason`). Proto můžete obdržet více notifikací o změnách stavu žádosti. Příklad: pokud požádáte o změnu z `PROCESSING_REDIRECT_NEEDED` na `READY_TO_SHIP`, obdržíte notifikace jak pro `PROCESSING_APPROVED`, tak pro `READY_TO_SHIP`.

> **POZN:** Přechod z `READY_TO_SHIP` není přes tento resource povolen. Místo toho použijte resource "Označit objednávku jako odeslanou/doručenou" podle vašeho životního cyklu objednávky.
