`POST /app-flow/v1/applications/{applicationId}/change-state`

Use this resource for changing Application state (`stateReason`) to a desired one. The following table contains the allowed transitions for this resource.

| Current stateReason of Application (from) | Available transitions (to) |
| --- | --- |
| `PROCESSING_REDIRECT_NEEDED` | `PROCESSING_APPROVED`, `PROCESSING_SIGNED`, `READY_TO_SHIP`, `REJECTED`, `CANCELLED_NOT_PAID` |
| `PROCESSING_APPROVED` | `PROCESSING_SIGNED`, `READY_TO_SHIP`, `CANCELLED_NOT_PAID` |
| `PROCESSING_SIGNED` | `READY_TO_SHIP`, `CANCELLED_NOT_PAID` |
| `READY_SHIPPED` | `CANCELLED_NOT_PAID` |
| `READY_DELIVERED` | `CANCELLED_RETURNED` |

> **NOTE:** This action simulates the real application process, which means that Application may be moved through one or multiple steps (`stateReason`). That is why you may receive multiple notifications about changes of Application's state. Example: if you request a change from `PROCESSING_REDIRECT_NEEDED` to `READY_TO_SHIP`, you will receive `PROCESSING_APPROVED` and `READY_TO_SHIP` notifications.

> **NOTE:** As you may see, no transition from `READY_TO_SHIP` is allowed for this resource. You should use the 'Mark order as shipped/delivered' resources according to your Order life cycle.

## Request

### Parameters

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `applicationId` | path | string | yes | Application ID, e.g. `01-11200a0ee1` |

### Body

Content type: `application/json;charset=UTF-8`

| Attribute | Type | Required | Description |
| --- | --- | --- | --- |
| `stateReason` | string (enum) | yes | Describes the internal state of the application, e.g. when state is `PROCESSING` — reason why the application remains in the processing state. Allowed values: `REJECTED`, `PROCESSING_APPROVED`, `PROCESSING_SIGNED`, `READY_TO_SHIP`, `READY_DELIVERED`, `READY_PAID`, `CANCELLED_NOT_PAID`, `CANCELLED_RETURNED` |

Example request:

```json
{
  "stateReason": "REJECTED"
}
```

## Responses

**200 OK** — application state was changed

```json
{
  "id": "01-11200a0ee1",
  "state": "PROCESSING",
  "stateReason": "PROCESSING_REDIRECT_NEEDED"
}
```

**404 Not Found** — application does not exist

```json
{
  "errors": [
    {
      "code": "APPLICATION_NOT_FOUND",
      "message": "Application 'NONEXISTING_APPLICATION' not found",
      "severity": "ERROR"
    }
  ]
}
```

**422 Unprocessable Entity** — transition is not allowed

```json
{
  "errors": [
    {
      "code": "NOT_SUPPORTED",
      "message": "Current application status not allows requested operation",
      "severity": "ERROR"
    }
  ]
}
```
